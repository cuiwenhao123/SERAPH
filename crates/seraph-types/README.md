# seraph-types

This crate is reserved for shared schema definitions, stable ID types, and serialization structures used across SERAPH components.

Planned responsibilities:

- stable IDs such as `cap_id`, `type_id`, `api_id`, `trait_id`
- `knowledge.json` structures
- Phase 1 `knowledge.json` structures
- Coverage and stage artifact structures retained by the current orchestration layer
- `coverage.json` structures
- stage input and output structures
